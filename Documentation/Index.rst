==================
TYPO3 x402 Paywall
==================

TYPO3 x402 Paywall gates TYPO3 pages and API routes with the x402 HTTP
payment protocol. It returns ``402 Payment Required``, verifies payment
signatures with a facilitator, logs settled payments, and shows payment
analytics in the TYPO3 backend.

..  important::

    This release supports TYPO3 14.3 and later only.
